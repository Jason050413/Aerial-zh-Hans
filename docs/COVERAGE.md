# 覆盖范围

目标版本：Aerial 4.1.7。当前翻译表 840 条。

## 已覆盖

| 区域 | 内容 |
|---|---|
| 菜单 | 主菜单、播放菜单、Dock 菜单 |
| 设置 | 侧边栏标题和副标题、各设置面板、下拉选项 |
| 视频库 | 侧边栏分类、内容标题、工具栏和工具提示 |
| 首页仪表盘 | 卡片标题、状态文字、显示模式说明 |
| 首次启动向导 | 卡片标题、说明、分步文字、感谢页 |
| 弹窗 | 退出、重置、缓存清理、迁移确认 |
| 系统提示 | 定位、Apple Events、App 数据、扩展名称 |

## 仍为英文

| 内容 | 原因 |
|---|---|
| 视频名称、地点、场景数据 | 由 Apple manifest 或来源提供 |
| 第三方扩展包名称、作者、简介 | 由扩展作者提供 |
| 部分动态错误信息 | 运行时拼接，尚未逐条接入 |
| 更新说明和 Sparkle 更新窗口 | 发布说明是英文内容，Sparkle 使用框架本地化 |
