## 仍可能显示英文

| 内容 | 原因 |
|---|---|
| 视频名称、地点、场景数据 | 上游内容，由 Apple manifest 或来源提供；通常跟随系统语言 |
| 第三方扩展包名称、作者、简介 | 由扩展作者提供，不属于界面 |
| 部分动态错误信息 | 由代码运行时拼接，尚未逐条接入本地化 |
| 部分复杂缓存迁移弹窗 | 包含数量、大小和路径的动态句子，尚未全部覆盖 |
| 更新说明和 Sparkle 更新窗口 | 发布说明是英文内容；Sparkle 自带框架本地化 |
| 资源补丁模式下的侧边栏 | 没有修改源码，`Text(String)` 仍不查表 |

## 资源补丁模式与源码构建的区别

| 方式 | 覆盖 | 是否修改源码 | 是否需要 Xcode |
|---|---|---|---|
| `scripts/apply.sh` | 直接字面量，约 673 条 | 否 | 否 |
| `scripts/build.sh` | 源码级，840 条 | 是 | 是 |
